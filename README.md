# CanStream

Bu depo, kişisel kullanım ve test amacıyla oluşturulmuş özel bir versiyondur.

---

### 
Bu projenin temel altyapısı, kod mimarisi ve tüm çözücü tabanı tamamen **Emre Kahveci**'ye aittir. Bu repository, kendisinin açık kaynaklı çalışması temel alınarak yalnızca kişisel kullanım amacıyla çatallanmış (fork); üzerinde bazı arayüz, kategori ve filtre özelleştirmeleri yapılmıştır.
